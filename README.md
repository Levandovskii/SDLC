## Описание проекта

Проект представляет собой Windows Forms приложение для оценки продуктивности пользователя и расчета уровня прокрастинации.

### Основные функции:
* **Ввод данных через диалоговое окно:** пользователь указывает количество дел, запланированных на день, и количество фактически выполненных.
* **Расчёт показателей:** вычисление коэффициента лени, определение уровня прокрастинации и вывод мотивационной или саркастической фразы.
* **Сохранение состояния:** запоминание последних введенных значений и их автоматическое восстановление при повторном открытии диалога.
* **Валидация:** проверка корректности введенных числовых данных и вывод сообщений при ошибках ввода.
* **Архитектура:** реализация логики на основе паттерна MVC (Model-View-Controller) с активной моделью.
